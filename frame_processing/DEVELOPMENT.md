## 구현 정책 (팀 최종 합의와 구분)

- SSIM 임계값은 생성자 필수 인자로 명시. 실험의 0.90은 임시 후보.
- 960px 색상 SSIM을 기본 전처리 후보로 사용. 원본 파일은 축소하지 않음.
- 실행 중 영역 변경은 거부. 일시정지에서 변경하면 P/R을 초기화하고 새 그룹.
- 일시정지 중 새 질문 캡처는 거부. 이미 접수한 질문 캡처는 완료 후 pause 복귀.
- pause/stop은 처리 중인 관측이 완료될 때까지 기다림. UI 작업 스레드에서 호출.
- 질문 스냅샷의 분류는 Unknown으로 즉시 반환. 정기 프레임만 분류 후보 적용.
- 오류 콜백에서는 Qt Signal 등으로 전달하고 즉시 반환. 예외를 외부로 던지지 않음.
- 미제출 질문·과거 대표 파일은 자동 삭제하지 않음.

### 성능 측정으로 발견한 문제와 수정

최초 scikit-image 색상 SSIM 직접 호출 방식은 1080p 합성 입력(비교용 긴 변 960px)에서
SSIM 두 번 중앙값 1005.799ms, 전체 중앙값 1101.047ms였음. 당시 벤치마크와 스모크를
함께 실행했으므로 부하 영향을 포함하며, 스모크는 10초 정기 관측 6개·간격 약 2초로
**1FPS 목표 미달**. 최초 도구는 이 상황에서 종료 코드 0을 반환했으나 성공 기준 미달로
기록하고, 개수·관측 간격을 검사하여 미달 시 실패하는 판정을 추가함.

이후 동일한 7×7 균일 창·색상 3채널·표본 공분산 공식을 OpenCV boxFilter와 float64로
계산하도록 수정. 잡음·균일 화면·색상 변경에서 참조 구현과 소수 10자리까지 일치 검증.
최적화한 측정은 벤치마크와 스모크를 순서대로 실행함. 따라서 아래 두 수치는 각각의
실행 결과이며 엄밀한 동일 부하 속도 배율 비교로 해석하지 않음.

최종 벤치마크 (`--iterations 12`, 합성 1920×1080, 비교 긴 변 960):

| 항목 | 중앙값 ms | p95 ms |
|---|---:|---:|
| 합성 화면 생성 (MSS 아님) | 3.768 | 6.926 |
| 비교 전처리 | 1.379 | 2.702 |
| SSIM 2회 | 265.312 | 602.034 |
| 휴리스틱 분류 | 41.357 | 64.383 |
| JPEG 저장 | 12.008 | 16.728 |
| 전체 | **308.209** | **686.856** |

최종 그래프 예제의 참조 SSIM 절대 오차 `7.771561172376096e-16`.
원본 결과: `sessions/benchmark_400c0fa5f31241e7abef38e84f09eca3/benchmark_report.json`.

최종 연속 실행:

```powershell
.\.venv\Scripts\python.exe -m frame_processing.smoke --synthetic --seconds 10 --threshold 0.985
```

정기 관측 **11개**, 질문 스냅샷 **2개**, 저장 이미지 **3개** (대표 1 + 질문 2),
정기 취득 간격 **988~1017ms**, `cadence_pass=true`. 시작·종료 경계에서 11개가 될 수 있음.
원본 결과: `sessions/2e8fae8bab4346a3b794878d449ea7d1/smoke_report.json`.

### 임계값 탐색: 확정값 없음

| 합성 예제 | SSIM |
|---|---:|
| 동일 화면 | 1.000000 |

| 약한 픽셀 잡음 | 0.988606 |
| 사각 주석 추가 | 0.983755 |

- 0.90/0.95는 이 그래프 변경도 놓침.

- 0.985는 이 예제들에서는 잡음/포인터와 의미 있는 변경을 구별.
- 0.99는 잡음도 변경으로 판정.
- 이는 합성 5종의 관찰 결과이며 실제 강의 임계값을 확정한 결과가 아님.
